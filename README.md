# Gemini Coder - AI 기반 풀스택 개발

이 프로젝트는 Gemini Coder 에이전트를 사용하여 웹 애플리케이션을 개발하는 과정을 보여줍니다.

## 시작하기

1.  **의존성 설치:**
    ```bash
    npm install
    ```

2.  **개발 서버 실행:**
    ```bash
    npm run dev
    ```

3.  **애플리케이션 접속:**
    [http://localhost:3000](http://localhost:3000)

## 테스트

```bash
npm test
```
